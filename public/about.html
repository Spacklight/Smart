About Miyoni and Smartbase

Company overview

Miyoni is a technology company that builds simple cloud tools for developers. Our product, Smartbase, lets you create databases, run SQL, store files and add "Sign in with Google" to your own website or app without running or maintaining any servers.

Mission

To make it easy for developers, students and small teams to store data, manage files and sign users in, so they can spend their time building their product instead of setting up infrastructure.

Vision

A world where anyone with an idea can build a reliable, real application using simple, affordable and well documented tools.

Products and services

  • Smartbase Databases - create databases and tables, browse records, and run SQL with joins, grouping, subqueries, views, indexes, constraints and transactions.
  • Smartbase REST API - read, write and collective API keys, pagination, structured errors and usage limits. Base address: https://smartbase.de5.net/apiv1.
  • Smartbase Files - upload, download and manage files (up to 50 MB each, 1 GB free) from the dashboard or with an API key, or send them to your own Backblaze B2 bucket.
  • Auth & Email - Google sign-in for your own websites, flexible storage for your users, one-account-one-device control, and email broadcasts with delivery and open tracking.
  • Documentation - full guides and API reference at https://smartbase.de5.net/docs.

Our story

Smartbase began as a simple idea: a SQL database platform that anyone can use from a phone or a laptop, built on Cloudflare's global network with durable cloud storage behind it. It started with databases, tables and a SQL editor. It then grew to include a full REST API with API keys, a more powerful SQL engine, file storage, and an authentication and email platform so developers can sign users in with Google and keep in touch with them. Today it runs on its own domain, smartbase.de5.net, and we continue to improve it based on what developers need.
